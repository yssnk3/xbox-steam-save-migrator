# Steam ↔ Xbox 存档移植工具

在 **Steam** 与 **Xbox PC Game Pass** 之间迁移游戏存档的桌面工具。自动扫描双端存档路径，一键完成格式转换与落盘校验，并提供 Xbox 游戏库直启与云同步防护。

> [!CAUTION]
> **⚠️ 存档移植存在失败风险，不保证成功 —— 使用前请务必读完这一节**
>
> 本工具通过逆向 Xbox WGS 容器格式并"就地替换字节"来搬运存档。**这是一项有风险的操作**：即使工具报告"移植成功"、文件尺寸与 MD5 校验全部通过，**游戏仍可能无法识别存档、读档崩溃，甚至原本的存档被覆盖**。校验通过只说明"字节写对了位置"，不代表游戏一定能解析该存档——存档的具体字节格式由各游戏自行决定。
>
> **可能失败的场景（非穷举）**
> - 两端存档字节布局不同（如《幻兽帕鲁》需外部转换工具），工具会拦截，但识别不覆盖所有游戏
> - Xbox 端尚未由游戏自身生成 WGS 容器结构（需先在 Xbox 端启动并存一次档）
> - 账号绑定类游戏（如《极限竞速：地平线 5》）存档跨账号无效
> - 云存档回滚：游戏内若弹窗选择"使用云端存档"，会覆盖刚移植的结果
> - 游戏或平台客户端未完全退出导致文件被占用
> - 未被识别的存档格式、版本不匹配的游戏更新
>
> **降低风险的必做步骤**
> 1. **移植前自行额外备份**重要存档，不要只依赖工具的自动备份
> 2. 完全退出游戏与 Xbox 应用（工具会尝试关闭，但不能保证）
> 3. 关闭云同步，或在弹窗时选择"使用本地存档"
> 4. 先用「移植预演（dry-run）」查看会写哪些槽位，确认无误再执行
> 5. 移植后启动游戏读档验证一次；出问题立即用备份恢复
>
> **适用范围**：仅适用于 Windows 本机、已在本机安装的游戏存档。不支持在线账号验证绕过、不修改游戏进程、不绕过 DRM。使用本工具产生的任何后果由使用者自行承担（详见文末免责声明）。

## 功能

**存档移植**
- 自动扫描 Steam（注册表 / libraryfolders.vdf / 多用户 userdata）与 Xbox（`Packages\<PFN>\SystemAppData\wgs\<XUID>`）存档路径
- 双端一键移植，写入前自动生成 ZIP 备份
- 落盘校验：文件尺寸、MD5 哈希、WGS 容器结构完整性（容器名 / GUID / 序号均不被改写）
- 移植预演（dry-run）：不写任何文件，先告诉你会写哪些槽位
- 任意目录手动移植、手动 WGS 容器解包 / 打包

**Xbox 游戏库**
- 一键扫描本机已安装的 Game Pass 游戏（AUMID 枚举，含图标与"是否有存档"标记）
- 一键启动游戏：走系统 `shell:appsFolder` 激活，**无需打开 Xbox 客户端**
- 云同步控制：停止云同步（尽力关闭 Xbox 应用全家桶 + GamingServices 服务），以及引导式上传云存档

**其他**
- 备份中心：查看 / 恢复 / 删除历史备份
- 存档格式识别：拖入任意路径自动判断属于哪款游戏（18/19 常见格式）
- 文件夹扫描：选定文件夹后自动扫描子目录，识别已知游戏并列出未识别存档，结果可逐个删除
- AI 诊断：失败现场自动分析、多轮追问、历史会话管理；支持配置任意 OpenAI 兼容接口
- 布局个性化：拖动面板边缘/角落调整尺寸与位置，松手自动保存，可一键恢复默认
- 深色 UI，中英文游戏名映射，Steam 图标本地代理

## 快速开始

环境要求：Windows 10/11、Node.js 18+

```bash
npm install
npm start          # 后端 :3001 + 前端 :5173
```

开发模式（带 Electron 窗口）：

```bash
npm run electron:dev
```

## 打包

```bash
npm run electron:build
```

产物在 `release/`：

| 文件 | 说明 |
|---|---|
| `Steam-Xbox-Save-Migrator 1.0.0.exe` | **单文件便携版**（约 77MB），双击即用，无需安装 |
| `win-unpacked/` | 免安装目录版，启动更快（不必先解压） |

> 首次运行单文件版需解压约 77MB，冷启动约 15–25 秒；目录版启动更快。

**数据存放位置**

| 运行方式 | 备份 / 配置 |
|---|---|
| 单文件 exe | `%LOCALAPPDATA%\Steam-Xbox-Save-Migrator\` |
| 目录版 / 开发模式 | 程序所在目录 |
| 自定义 | 设置环境变量 `SXSM_DATA_DIR` 指向任意目录 |

> 单文件版每次运行会解压到新的临时目录，因此数据绝不能放在程序目录——否则关闭后备份和 AI 配置会全部丢失。

**环境变量**

| 变量 | 作用 |
|---|---|
| `SXSM_DATA_DIR` | 覆盖数据根目录（备份 / 配置 / 缓存 / AI 历史都会写到这里） |
| `SXSM_PORT` | 覆盖后端监听端口（默认 `3001`） |

**隐私与密钥**

- AI 诊断使用你自填的 OpenAI 兼容接口（Base URL / Model / API Key），配置只保存在本机 `settings.json`，**不会随仓库提交**（`.gitignore` 已排除）。
- 存档路径、机器名等现场信息在发送给模型前会做脱敏（只保留路径末两级）。
- 不启用 AI 功能时，工具完全离线运行，不发起任何外部请求。

> **打包失败排查**：若 `electron-builder` 报 `rcedit.exe` / `elevate.exe` 不存在，通常是杀毒软件隔离了 `%LOCALAPPDATA%\electron-builder\Cache` 下的工具。处理方式二选一：把该目录加入杀软白名单，或用官方 NSIS 发行包补齐 `nsis-3.0.4.1/` 目录（其中 `Bin/makensis.exe` 必需，`elevate.exe` 便携版下不会被调用，放任意合法 exe 占位即可）。当前仓库配置了 `signAndEditExecutable: false`，可绕开 rcedit 步骤（代价是 exe 缺少图标与版本信息）。

## 使用须知

- **移植前请完全退出游戏和 Xbox 应用**。工具会检测进程占用并尝试自动关闭 Xbox 应用，但游戏本体需你手动退出。
- **Steam → Xbox 方向需要先在 Xbox 端启动过该游戏并产生存档**。WGS 的容器清单（容器名 / GUID）必须由游戏自身生成，工具只做"就地替换字节"以保结构，不会凭空创建容器。
- **云存档冲突**：若游戏内弹出存档选择框，请选择"使用本地存档"，否则云端旧档会覆盖刚移植的结果。可用"停止云同步"先行切断。
- 移植完成后建议启动游戏读档确认一次。文件层面的校验通过不代表游戏一定能解析该存档（各游戏存档字节格式由游戏自身决定）。
- 部分游戏不支持直接移植：如《幻兽帕鲁》两端 `.sav` 字节布局不同，需借助 `palworld-save-tools` 等外部工具转换；账号绑定类游戏（如《极限竞速：地平线5》）存档跨账号无效。

## 支持的游戏

内置数据库收录 30 款游戏（24 款直接支持、5 款需先启动游戏生成结构、1 款需外部转换工具），另有 9 款可识别但不支持一键移植。可在界面中通过"自定义游戏"添加数据库未收录的游戏。

## 技术说明

- 后端：Node.js + Express（`server/`）
- 前端：React 18 + TypeScript + Vite + Tailwind（`src/`）
- 桌面壳：Electron（`electron/`）
- WGS 容器格式：已逆向 Xbox 真实 v14 格式（`containers.index` + `container.N`，混合端序 GUID，160 字节定长描述符）
